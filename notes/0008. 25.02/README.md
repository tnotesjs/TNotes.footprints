## 2. 25.02.14

::: footprints 2025-02-14

对于 flutter、react native，我目前也仅仅是简单了解过，并没有啥实战经验。

看到简历的时候发现都是 8、9 年工作经验的，想到自己才 3 年不到，心里甚是发虚。

不过面完第一个之后，我就立刻跑到好 xd 那去装逼了。

我跟你说，我今天面试别人了，🐂🍺 不？……

最后记录一下这一周实际面下来的整体感觉吧！
